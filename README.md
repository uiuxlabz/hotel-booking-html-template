# GRANDEHOTEL — Luxury Hotel Booking Template

> *"Where Every Stay Becomes a Story."*

A premium, framework-free HTML template for luxury hotel booking websites. Built with semantic HTML5, modern CSS custom properties, and vanilla JavaScript. No dependencies required.

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | [`index.html`](index.html) | Hero with booking search, room showcase, about teaser, amenities grid, testimonials, CTA |
| About | [`about.html`](about.html) | Heritage story, company history, team members, values and stats |
| Services | [`services.html`](services.html) | Service cards (Spa, Dining, Events, Butler), amenities detail, video section |
| Contact | [`contact.html`](contact.html) | Contact info cards, booking inquiry form with data-form, map placeholder, hours table |
| Rooms | [`rooms.html`](rooms.html) | Full room listing with images, detailed descriptions, prices, feature comparison table |

---

## Features

- **Pure HTML/CSS/JS** — Zero frameworks, zero build tools
- **Responsive** — 980px 2-col, 720px 1-col with burger menu
- **Booking Form** — Date validation, check-in/check-out logic, form submissions
- **Scroll Reveal** — IntersectionObserver-powered fade-in animations
- **Hero Carousel** — Auto-rotating background images
- **Mobile Navigation** — Full-screen overlay with animated burger toggle
- **Gold Design System** — Navy/gold/cream luxury palette with Playfair Display + Inter

## Getting Started

1. Place your images in `assets/img/` using the filenames above
2. Open `index.html` in a browser — no server required
3. Customize colors in `style.css` `:root` variables
4. Edit content directly in the HTML files
